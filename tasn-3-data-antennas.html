2. Serial, parallel, synchronous, asynchronous

1 · Data
  • Parallel: all bits at once on N lines (short distances); serial: one after another on one line (long distances)
  • Asynchronous: each character carries start and stop symbols (telex); simple but slower
  • Synchronous: continuous flow, receiver clock synchronised once; faster, more complex (links between exchanges)
Narration

Data communication moves characters from one point to another, today almost always between computers. In parallel transmission every bit of a character travels at the same time on its own line, which is fast but needs many lines, so it is only used over very short distances; the handwritten notes show the historical example of Salvà's telegraph, one wire per letter. In serial transmission the bits travel one after another on a single line, which takes longer but is the only practical solution over long distances. A serial link must tell the receiver where each word starts and ends: in asynchronous transmission every character carries its own start and stop symbols, as drawn here, so the circuits are simple, but the extra symbols carry no user information and the gap between characters is not fixed. In synchronous transmission there are no start or stop symbols: a special sequence synchronises the receiver's clock once, and then a continuous flow of symbols is kept even when there is nothing to send, which is faster but needs more sophisticated equipment, as in the digital links between telephone exchanges.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §5.1–5.2; Handwritten notes Telecom II (scan 004)

3. Binary and M-ary signals

1 · Data
Narration

A binary signal takes one of two values in each symbol interval, and an M-ary signal one of M values. Nothing forces data transmission to be binary: with four voltage levels, each level carries two bits, and in general M symbols represent n bits when M equals 2 to the n. In the figure, the binary signal needs twelve symbols to send twelve bits, while the 8-ary signal sends the same twelve bits with only four symbols, three bits each, so it is three times faster at the same symbol rate. Problem 3.8 is the inverse question: to code the five vowels you need at least 3 bits, because 2 bits only give four words and 3 bits give eight.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §5.3, eq. 86, fig. 5.1; Barlabé, Exercicis i problemes (2020), answer key 3.8

4. Baud versus bit per second

1 · Data
  • Signalling rate r_s = symbols per second, in baud
  • Theoretical maximum through a channel of bandwidth B: r_s,max = 2B
  • Information rate r_b = bits per second = r_s · n, with M = 2^n levels
  • Binary synchronous: r_b = r_s; binary asynchronous: r_b < r_s; M-ary synchronous: r_b > r_s
  • V.34 modem: 1.5 kHz → 3 000 baud, but 33 600 bit/s thanks to many levels
2Bmax baud in bandwidth Br_s · log2 Mbit/s33 600 bit/sV.34 at 3 000 baud

Equations

rs,max​=2B  [baud],rb​=rs​log2​M=nrs​  [bit/s],M=2n
Narration

Do not confuse the two rates, it is a favourite trap. The signalling rate is the number of symbols per second, measured in baud, and a channel of bandwidth B allows at most 2 B baud, a limit only reached with special pulse shapes. The information rate is the number of bits per second, which equals the baud rate times the number of bits per symbol, n, where M equals 2 to the n levels. The two coincide only in a binary synchronous link; in a binary asynchronous link the bit rate is lower than the baud rate because of the start and stop symbols; and in an M-ary synchronous link the bit rate is higher. That is how old telephone modems worked: half a telephone channel, about 1.5 kHz, allows 3 000 baud, yet the V.34 standard reached 33 600 bits per second with multilevel symbols.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §5.3, eq. 87; Barlabé, FAQ_03 (2021) 15.R, 16.R

6. More levels, more errors

1 · Data
  • Same S/N and same baud: more levels → levels closer together → noise crosses the thresholds more easily
  • 2016 Q8: binary vs 16 levels → the 16-level signal has the larger error probability
  • So levels cannot grow forever; coding compensates part of the penalty
Narration

If multilevel signals carry more bits per symbol, why not use thousands of levels? Because, for the same signal power, more levels means the levels are closer together, and noise pushes the received value across a decision threshold more easily, as the handwritten notes sketch. These curves show it: at any given signal to noise ratio, the error probability grows with the number of levels. So in the 2016 partial, with the same signal to noise ratio and the same signalling rate, the 16-level signal has a larger error probability than the binary one. In the presence of noise you cannot make a digital signal look more and more like an analog one; coding is then used to recover part of the reliability.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §5.3, fig. 5.2; Partial 2016 Q8; Handwritten notes (scan 004)

7. Source coding and channel coding

2 · Coding
  • Coding acts on the symbols (modulation acts on the signal)
  • Source coding: remove redundancy → fewer bits. Morse (short words for frequent letters), ZIP/RAR (lossless), JPEG/MPEG/MP3 (lossy)
  • Channel coding: ADD bits to detect/correct errors and keep sync: parity bit, block codes, Hamming, convolutional (Viterbi)
  • Parity: detects 1 error, not 2, corrects none
  • Hamming (7,4): 16 words of 7 bits differing in ≥ 3 bits → detects 1–2 errors, corrects 1

Equations

detects d−1 errors,corrects ⌊2d−1​⌋ errors
minimum distance d of a block code (Hamming (7,4): d = 3)
Narration

Modulation is processing of the signal; coding is processing of the symbols of the digital message. Source coding removes redundancy so that the source is represented with fewer bits: Morse does it by giving the shortest words to the most frequent letters, like a single dot for E, compressors like ZIP do it without loss, and JPEG, MPEG or MP3 do it with an imperceptible loss; reducing the number of bits is exactly the 'main objective of source coding' asked in the question sheet. Channel coding does the opposite: it adds bits to detect and correct transmission errors and to keep synchronism, with parity bits, block codes, Hamming codes and convolutional codes decoded with the Viterbi algorithm. A single parity bit detects one error, misses two, and corrects none. The Hamming code of the notes maps 4 data bits into 7, choosing 16 of the 128 possible words so that any two differ in at least three bits, so one or two errors are detected and a single error is corrected by picking the closest valid word; the price is redundancy. For the exam, 'name a source code and a channel code' has a ready answer: Morse or ZIP for source, parity or Hamming for channel.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §5.4, table 5.1; Partials 2016 Q9, 2023 Q11; Questions_Telecom_1 Q10

8. Line codes

2 · Coding
Narration

The last family of channel codes shapes the electrical waveform: line codes. Binary signals can be unipolar or bipolar, and return to zero, R Z, if they go back to zero during half of the bit, or non return to zero, N R Z, if they hold the level for the whole bit. A long run of zeros in unipolar format has no transitions, so the receiver loses bit synchronism, and a long run of ones leaves a non-zero mean, a DC component, which transmission systems must avoid. A M I, alternate mark inversion, makes successive ones alternate in polarity, which removes the DC component, but a long run of zeros is still a flat line with no transitions; H D B three, not drawn here, fixes that by replacing every run of four zeros with a pattern containing pulses, so the receiver keeps synchronism. Local networks use the Manchester code, with a guaranteed transition in the middle of every bit: no DC and easy synchronism, but at the cost of a larger transmission bandwidth.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §5.4.2.2, fig. 5.6–5.8

9. Passband data: ASK, FSK, PSK and the modem

2 · Coding
Narration

Long-distance data links modulate a sinusoidal carrier, and with a digital modulating signal amplitude, frequency and phase modulation are called ASK, FSK and PSK. Facing noise, for a given signal to noise ratio, PSK gives the lowest error probability, followed by FSK, and ASK is the worst. A modem, short for modulator-demodulator, is the equipment that converts a low-pass digital signal into a band-pass digital signal and back, which is the answer to 'what is a modem' in the 2023 partial. To go faster, modems combine amplitude and phase, and such multilevel signals are drawn as a constellation: one dot per symbol at the tip of its phasor, here twelve phases, the four inner points sharing four of them, and two amplitudes: sixteen symbols. Above the line codes, communication protocols, organised in the seven layers of the I S O O S I model, decide who talks, how errors are reported and how packets are routed.

Sources: Barlabé, Introducción a la Telecomunicación (II), rev. 2023, §6, fig. 6.1–6.6, §5.5; Partial 2023 Q12

10. The A/D converter, block by block

3 · A/D
  • Anti-aliasing filter: makes the signal band-limited to W BEFORE sampling
  • Sampler: takes x(nTs) every Ts = 1/fs → discrete signal
  • Quantizer: assigns the nearest of a finite set of levels → multi-level digital signal
  • Coder: N-bit binary word per sample → binary signal with Tb = Ts / N
Narration

Analogue to digital conversion is the last topic of the exam scope, and its block diagram is a sure question. First comes the anti-aliasing filter, an analogue low-pass filter that guarantees a signal band-limited to W at the input of the sampler; that is why a filter is needed as the first stage, to avoid aliasing. Then the sampler measures the signal at regular instants separated by the sampling period T s, giving a discrete signal. Then the quantizer assigns to each sample the nearest of a finite number of amplitude levels, giving a multilevel digital signal. Finally the coder replaces each level by an N-bit binary word, so the bit time is the sampling period divided by N. Filter, sampler, quantizer, coder: memorise the four names in this order, in Catalan if you like: filtre anti-aliasing, mostrejador, quantificador, codificador.

Sources: Barlabé, Conversió A/D i D/A (2020), §2, fig. 2; Questions_Telecom_1 Q8–Q9

11. Sampling, Nyquist and aliasing

3 · A/D
  • Spectrum of the sampled signal: X(f) repeated every fs
  • No overlap ⟺ fs ≥ 2W (Nyquist rate 2W)
  • Overlap = aliasing: irreversible distortion
  • Real filters need margin: CD audio 20 kHz → fs = 44.1 kHz, not 40

Equations

xs​(t)=n∑​x(nTs​)δ(t−nTs​)⟷Xs​(f)=fs​k∑​X(f−kfs​)
fs​≥2W
no overlap of the replicas (Nyquist)
Narration

Why must the sampling frequency be at least twice the bandwidth? The spectrum of a sampled signal is periodic: the original spectrum, of width W on each side, is repeated around every multiple of the sampling frequency. As long as f s is at least twice W, the copies do not touch, and an ideal low-pass filter can recover the original exactly. Watch what happens as the sampling frequency is lowered: below twice W the replicas overlap, and the sum in red no longer looks like the original; this is aliasing, a distortion that nothing can undo afterwards. The minimum, twice W, is the Nyquist frequency, and because real filters need a transition band we sample a little faster: the compact disc samples 20 kHz audio at 44.1 kHz instead of 40.

Sources: Barlabé, Conversió A/D i D/A (2020), §2.2, eq. 3–5, §3.2

12. Quantization and coding

3 · A/D
256 levels8 bits: voice, phone, pilot-ATC65 536 levels16 bits: CD, per channelTb = Ts / Nbit time

Equations

L=2N levels,Δ=2NVpp​​,Tb​=NTs​​
SQNR≈6.02N+1.76 dB
standard result for a full-scale sinusoid (not in the course notes)
Narration

The quantizer is a non-linear system, so it has no transfer function; it is described by its staircase input-output characteristic. Its error, the difference between each sample and the nearest level, cannot be corrected when converting back, but it becomes negligible with enough levels. Voice, in telephony or between pilot and controller, needs 256 levels, 8 bits, while high-quality music on a CD uses 65 536 levels, 16 bits, per stereo channel. The quantization steps need not be equal: non-uniform quantizers use smaller steps for the most probable values of the signal. After coding, each sample becomes N bits, so the binary signal is N times faster than the multilevel one, and the converter is characterised by its number of bits per sample together with its maximum sampling frequency.

Sources: Barlabé, Conversió A/D i D/A (2020), §2.3–2.4

Here is the numerical example of the notes, a perfect exam question. Sampling at 8 kHz gives one sample every 125 microseconds, and 256 levels need 8 bits per sample. Eight bits must fit in 125 microseconds, so each bit lasts 15.625 microseconds, giving 64 000 baud. In a binary synchronous link the bit rate equals the baud rate: 64 kilobits per second, the classic telephone channel. And since a channel of bandwidth B carries at most 2 B baud, the minimum bandwidth is 32 kHz, far more than the 8 kHz that the notes quote for analog transmission: digital pays in bandwidth, which is why compression algorithms such as M P 3 or JPEG were developed.

14. D/A conversion

3 · A/D
  • Much simpler than A/D: decoder + low-pass filter
  • Ideal LPF on the sampled spectrum gives back X_BL(f) exactly (if fs ≥ 2W)
  • Only remaining difference: the quantization error, negligible with enough bits
Narration

Digital to analogue conversion is much simpler. A decoder turns the binary words back into a multilevel signal, and a low-pass filter removes the spectral replicas created by sampling, leaving only the original band. If the sampling respected Nyquist, the recovery is perfect, at least in theory. The only difference between the original and the recovered signal is the small quantization error introduced in the A to D step.

Sources: Barlabé, Conversió A/D i D/A (2020), §3

15. Plane waves and wave phenomena

4 · Propagation
  • Plane wave: E ⊥ H ⊥ k; η = √(μ/ε) (377 Ω in vacuum) ↔ Z0 of a line
  • k = ω / v_p, v_p = 1/√(με); n = √ε_r
  • Reflection: θr = θi; refraction (Snell): n1 sin θi = n2 sin θt, angles from the NORMAL
  • Split E into ⊥ and ∥ to the plane of incidence (ground: horizontal pol. = ⊥, vertical pol. = ∥): different reflection coefficients → oblique linear polarization changes on reflection
  • Diffraction: the wave 'goes round' obstacles (Huygens principle): coverage behind hills, softer interference

Equations

η=εμ​​ (377 Ω in vacuum),vp​=με​1​,k=vp​ω​,n=εr​​
θr​=θi​,n1​sinθi​=n2​sinθt​
angles from the normal
Narration

Now propagation, starting with the plane wave, the simplest solution of Maxwell's equations and a good local model of any wave far from its antenna. In a plane wave the electric field, the magnetic field and the direction of propagation are mutually perpendicular, and the ratio between E and H is the intrinsic impedance of the medium, the square root of mu over epsilon, about 377 ohms in vacuum, the analogue of the characteristic impedance of a line. The wave number is omega over the propagation speed, which is one over the square root of mu epsilon, and the refractive index is the square root of the relative permittivity. At a discontinuity, part of the wave is reflected, with the angle of reflection equal to the angle of incidence, and part is refracted into the second medium following Snell's law, n 1 sine theta i equals n 2 sine theta t, with all angles measured from the normal to the surface. The reflection coefficient depends on both media, on the angle of incidence and on the polarization: decompose the electric field into a component perpendicular to the plane of incidence and one parallel to it; for a reflection from the ground, a horizontally polarized wave is the perpendicular case and a vertically polarized wave the parallel one; each has its own reflection coefficient, so an oblique linear polarization generally comes back with a different orientation, or even elliptical. Diffraction is what cannot be explained by reflection or refraction: by Huygens' principle every point of a front radiates a new wave, so waves go round obstacles, which gives some coverage behind hills.

Sources: Barlabé, Notes sobre propagació radioelèctrica (2020), slides 2–13

16. Propagation mechanisms by frequency

4 · Propagation
Narration

The main propagation mechanism depends on the frequency band. Below about 100 kHz, waves are guided between the Earth's surface and the ionosphere; this was used by the old Omega and Loran navigation systems, and today only for communications with submarines. Between 100 kHz and 3 MHz the surface wave dominates, following the ground; it needs vertical polarization, which is why the NDB and ADF system uses vertically polarized antennas, and AM broadcasting lives here too. Between 3 and 30 MHz, waves bounce off the ionosphere, reaching very long distances, farther at night because the lower layer rises. Above 30 MHz propagation is optical, along the line of sight, with a direct wave and a ground-reflected wave in the troposphere: this is where aeronautical VHF voice, VOR, DME, TACAN, secondary radar and satellite systems work, and it is the regime for all the Friis problems.

Sources: Barlabé, Notes sobre propagació radioelèctrica (2020), slide 2 comments, fig. 1–4

17. Polarization of a plane wave

4 · Polarization
  • Polarization = orientation in space of the E field, i.e. the curve traced by the tip of E at a fixed point
  • In phase (or anti-phase) components → linear; 90° apart → elliptical; 90° apart AND equal amplitude → circular
Narration

Polarization is the orientation in space of the electric field of the wave, the definition asked word for word in 2016 and in the question sheet. To see it, fix a point, for example z equal to zero, and follow the tip of the electric field vector as time passes. If the field has a single component, or two components in phase, the tip moves along a line: linear polarization, vertical, horizontal or oblique. If the two components are 90 degrees apart, the tip draws an ellipse, and if they are also equal in amplitude, a circle. Watch the four cases: vertical, oblique x plus 2 y, circular x minus j y, and elliptical 2 x minus j y. Antennas take the name of the polarization they radiate far away: a vertical dipole is vertically polarized, and aeronautical voice antennas use vertical polarization.

Sources: Barlabé, Notes sobre propagació radioelèctrica (2020), slides 5–9; Barlabé, FAQ_03 (2021) 8.R, 10.R; Partial 2016 Q10; Questions_Telecom_1 Q1

19. What an antenna is

5 · Antennas
  • Transition region between a GUIDED wave (line) and a RADIATED wave; can give directionality
  • Far field (Fraunhofer zone): locally a plane wave
  • Isotropic radiator: equal in ALL directions of space (ideal, impossible); omnidirectional: equal in all directions of a PLANE
  • Broadcast: omnidirectional transmitter, directive receivers (or omni if several transmitters); point to point: both very directive; radar: rotating directive antenna
  • Reciprocity (Lorentz): same pattern and parameters transmitting and receiving
  • 2022 Q3: aeronautical voice antenna on an aircraft → omnidirectional in the horizontal plane, vertical polarization
Narration

An antenna is the transition region, the interface, between a wave guided by a transmission line and a wave radiated into space, and it can also give the radiation a direction; opening up the end of a two-wire line is how the dipole was born. Far from the antenna, in the far-field or Fraunhofer zone, the wave arriving at a receiver can be treated locally as a plane wave. Do not confuse isotropic and omnidirectional: an isotropic radiator radiates equally in every direction of space and cannot physically exist, while an omnidirectional antenna radiates equally in all directions of one plane. Each system needs its antenna: broadcasting uses an omnidirectional transmitter and directive receivers, or omnidirectional ones if there are several transmitters; a point to point link uses two very directive antennas; and a radar uses a rotating directive antenna. By Lorentz reciprocity, the same antenna transmits and receives with the same pattern, so we simply speak of the radiation pattern. So the 2022 question about the pattern of an aeronautical voice antenna on an aircraft has this answer: omnidirectional in the horizontal plane, because the ground stations can be in any direction, with vertical polarization.

Sources: Barlabé, Introducció a les antenes de telecomunicació (2020), §2–3, §5.1; Partial 2022 Q3; Projecte antena (specifications)

Narration

Barlabé's slides on antenna structures are a picture gallery, so for the exam just know the families and where they are used. Dipoles, usually half a wavelength long, and their arrays, as in the ILS localizer; folded dipoles; and quarter-wave monopoles over a ground plane, sometimes with a capacitive load or inside a fairing. Slots and slot arrays, common in radars, travelling-wave antennas, horns, and parabolic reflectors such as the Cassegrain, the offset and the Gregorian. Helical antennas, Yagi-Uda arrays, microstrip patches like those of the SMOS satellite, lenses, and wideband designs such as the biconical, the discone, the log-periodic and fractal antennas. On aircraft, the NAV COM antennas are monopoles or dipoles, inside fairings on fast aircraft, which is exactly your course project: a vertical quarter-wave monopole or half-wave dipole for the voice band, 118 to 137 MHz, centred at 127.5 MHz, where the wavelength is 2.35 m, so about 59 centimetres or 1.18 metres before end corrections.

21. The Friis transmission equation

5 · Antennas

{ui["steps"]}

isotropic: P=4πR2PT​​
antenna: P=4πR2PT​​DT​(θ,φ)
receiver: PL​=PAef​
Aef​=4πλ2​D
PL​=PT​DT​DR​(4πRλ​)2∏ci​
Narration

Now the most important formula of the partial, derived in four steps. An isotropic radiator in a lossless medium spreads its power P T over a sphere, so at distance R the power density is P T over 4 pi R squared, falling with the square of the distance: 6 dB every time the distance doubles. A real antenna concentrates power in some directions; the directivity function D of theta and phi is the ratio between its power density and the isotropic one, so the density towards the receiver is multiplied by D T. The receiving antenna behaves like a funnel: the power it delivers to its load is the incident density times its effective area A ef. Reciprocity links the two parameters: the effective area is lambda squared over 4 pi times the directivity. Putting it together: P L equals P T times D T times D R times lambda over 4 pi R squared, times the product of loss coefficients c i, each between zero and one, for medium losses, polarization mismatch, mispointing, mismatch and efficiency; and, as the FAQ insists, everything in linear units, watts and metres.

Sources: Barlabé, Introducció a les antenes de telecomunicació (2020), §4 and §6, eq. 9–38; Barlabé, FAQ_03 (2021) 6.R

23. Radiation pattern parameters

5 · Antennas
  • Normalised pattern t(θ, φ) = D(θ, φ) / D, usually in dB, polar plot
  • Main lobe (0 dB) and secondary lobes
  • Beamwidth at −3 dB (half power) and between nulls
  • Main-to-secondary lobe level (NLPS): 0 dB minus the LARGEST secondary lobe
  • Front-to-back ratio: main lobe vs the lobe at 180°
  • Gain G = efficiency × D (G ≈ D unless the antenna is damaged); radiation resistance R_rad models the radiated power

Equations

t(θ,φ)=DD(θ,φ)​,G=eD,NLPS=0 dB−(largest secondary lobe)
Narration

The radiation pattern draws the power density radiated at a fixed distance as a function of direction, normalised to its maximum and usually in decibels on a polar plot. The biggest lobe, at 0 dB, is the main lobe, and all the others are secondary lobes. The beamwidth is the angular width of the main lobe between the points where it falls to minus 3 dB, half power, or between its nulls. The main to secondary lobe level, N L P S in Catalan, is the difference in decibels between the main lobe and the largest secondary lobe, wherever it is. The front to back ratio compares the main lobe with the lobe 180 degrees behind it. Finally, the gain refers to the power delivered to the antenna rather than radiated, so gain equals efficiency times directivity, practically equal unless the antenna is damaged; and the radiation resistance is the resistor that would dissipate the same power the antenna radiates.

Sources: Barlabé, Introducció a les antenes de telecomunicació (2020), §5.1–5.3; Barlabé, FAQ_03 (2021) 8.R

24. Antenna impedance and effective length

5 · Antennas
  • Z_ant = V/I at the terminals; same value transmitting or receiving (reciprocity)
  • R_rad: resistor that would dissipate the power the antenna RADIATES
  • Z_ant = R_ant + jX_ant with R_ant = R_rad + R_Ω (ohmic loss, usually ≈ 0)
  • Receiving: Thévenin source V_ant (open-circuit voltage) behind Z_ant
  • Effective length l_ef = V_ant / E (metres; not the physical length); A_ef = η l_ef² / (4 R_ant)

Equations

Zant​=Rrad​+RΩ​+jXant​,Vant​=lef​E
Aef​=4Rant​ηlef2​​
η here is the intrinsic impedance, 377 Ω
Narration

Two more antenna parameters complete the notes, and both are about connecting the antenna to a circuit. The antenna impedance is the ratio of voltage to current at its terminals; by reciprocity it is the same whether the antenna transmits or receives. To the generator, a transmitting antenna looks like a resistor that dissipates the radiated power: that resistor is the radiation resistance. The improved model adds the ohmic loss resistance of the metal, usually negligible, and a reactance, so the impedance is R rad plus R omega plus j X ant. When receiving, the same impedance sits in series with a source, the open-circuit voltage V ant that the incident wave induces at the terminals. The effective length is that open-circuit voltage divided by the incident electric field; it has units of metres but is not the physical length, and it relates to the effective area through A ef equals eta, the intrinsic impedance of free space, about 377 ohms, times l ef squared over four R ant.

Sources: Barlabé, Introducció a les antenes de telecomunicació (2020), §5.3–5.4, fig. 23–30, eq. 26–30
